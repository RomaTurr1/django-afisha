# 🎟️ Афиша мероприятий (Django)

Веб-приложение для просмотра, поиска, фильтрации и добавления мероприятий (концерты, мастер-классы, выставки, лекции, турниры).

Проект разработан в рамках практической работы по Django.

---

## 🚀 Реализованный функционал

### 1. Модели и база данных
- **`Category`** — модель категорий событий (поле `name`).
- **`Event`** — модель мероприятий со связью `ForeignKey` к категории:
  - `title` — название мероприятия;
  - `description` — подробное текстовое описание;
  - `location` — место проведения;
  - `event_date` — дата и время проведения (`DateTimeField`);
  - `price` — стоимость билета (`DecimalField`, для бесплатных мероприятий = `0`);
  - `is_finished` — отметка о завершении события;
  - `category` — привязка к категории;
  - Метод `__str__` и вычисляемое свойство `is_free`.
- Модели зарегистрированы в панели администратора Django с поиском, фильтрами и отображением колонок.

### 2. Главная страница (Список событий)
- Вывод карточек всех мероприятий, отсортированных по дате проведения по возрастанию (`order_by('event_date')`).
- Для каждого события отображаются: название, категория, дата и время, место проведения, стоимость и кнопка «Подробнее».
- Для событий с нулевой стоимостью отображается плашка **«Бесплатно»**.
- Если база пуста — выводится сообщение: *«Мероприятий пока нет»*.
- Быстрая кнопка «Добавить мероприятие».

### 3. Поиск и фильтрация (GET-параметры)
- Поиск по части названия события (`icontains`).
- Фильтрация по категории через выпадающий список + пункт «Все категории».
- **Поиск и выбор категории работают одновременно** (например, категория «Мастер-классы» + слово «Python»).
- Сохранение введенных параметров поиска и выбранной категории в полях формы после отправки.
- Кнопка «Найти» и ссылка «Сбросить».
- При отсутствии результатов выводится сообщение: *«По вашему запросу ничего не найдено»*.
- Дополнительный фильтр: чекбокс *«Только бесплатные»*.

### 4. Страница подробностей о событии
- Полная информация о событии: категория, дата и время, локация, статус, стоимость, подробное описание.
- Ссылка для возврата к общему списку.
- Кнопки для быстрого редактирования и удаления.

### 5. Создание и управление мероприятиями
- Страница добавления события с валидацией формы (`ModelForm` / `CreateView`).
- Выбор категории из базы данных.
- Виджет ввода даты и времени `type="datetime-local"`.
- Защита от CSRF-атак (`{% csrf_token %}`).
- Перенаправление на главную страницу после успешного сохранения.
- **Бонусные функции**:
  - Редактирование события через `UpdateView`;
  - Удаление события с подтверждением через `DeleteView`.

## 🛠️ Установка и запуск проекта

### 1. Клонирование репозитория
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd AfishaPractice
```

### 2. Создание и активация виртуального окружения
- **macOS / Linux:**
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  ```
- **Windows:**
  ```bash
  python -m venv .venv
  .venv\Scripts\activate
  ```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Применение миграций
```bash
python manage.py migrate
```

### 5. Создание суперпользователя и генерация демо-данных
Вы можете выполнить автоматическую команду, которая создаст суперпользователя и наполнит базу категориями и разнообразными событиями:
```bash
python manage.py setup_demo_data
```
> Данные для входа в панель администратора:
> - **Логин:** `admin`
> - **Пароль:** `admin123`
> - **Адрес панели:** `http://127.0.0.1:8000/admin/`

Либо создать суперпользователя вручную:
```bash
python manage.py createsuperuser
```

### 6. Запуск сервера разработки
```bash
python manage.py runserver
```

Откройте в браузере: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
